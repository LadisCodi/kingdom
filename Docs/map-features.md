Map Features
---

Each map cell can contain the following features:

- Nothing.
- Forest. Provides wood when tapped or worked. It grows back after some time.
- Berries. Provides food when tapped. It disappears when empty.
- Wild animals. Provides food when tapped. It disappears when empty.
- Stone. Provides stone when tapped or worked. It disappears when empty, but will spawn back after some time in any adjacent tile from its origin.
