# World menus — the prompts (2026-10-07)

Mockups m83–m89 for [`Docs/proposals/world-menus.md`](../../../proposals/world-menus.md).
One ChatGPT chat per mockup, run in parallel tabs.

Attached to every message (`m83-refs/`):

1. `ref-city-menus.jpg` — the city's menus as shipped (district card,
   upgrade, lair attack, builders, survey).
2. `ref-world-now.jpg` — the world's sheets today (the content to keep).
3. `ref-hex-art.jpg` — the hex art the board draws.
4. `ref-world-board.jpg` — m64, the world board, for the backdrop.
5. `ref-ui-kit.jpg` (m80's) — the kit's pieces.
