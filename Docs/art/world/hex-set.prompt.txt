WORLD HEX SPRITES — THE FULL SET for the game "Kingdom". Follow this file exactly.

GENERATE NEW IMAGES. Do not edit or export the attached files: they are ONLY style references.
- approved-sheet1.png = TWO HEX SPRITES ALREADY APPROVED (left: forested mountain; right: fertile land with game). THE STYLE IS LOCKED ON THEM: same render, same saturation, same outline softness, same light from above, same scale of trees, rocks, fields and animals, same camera. Every sprite of this set must look like it was made in the same session.
- ref-board.png = the world board these sprites live on.
- ref-assets.png = sprites that already ship in the game.

WHAT A SPRITE IS (same rules as approved-sheet1.png)
- The CONTENT of one hex of the world board, standing on a separate ground tile the game draws under it. NO ground plate, NO base, NO hex outline, NO drop shadow. Only the objects, on full transparency. (Small tufts of grass or bushes between objects are fine, as in approved-sheet1.png.)
- Camera: from a little south of overhead, objects seen from a high three-quarter angle, standing upright.
- Footprint: a hex tile seen at this tilt has a top face like an elongated hexagon, about 1.4 times wider than tall. Every object stands inside it; things may rise above it.
- Draw as if shown about 130 px wide on a phone: big readable shapes, no tiny details.
- VARIANTS of the same thing must be clearly the same kind of place, at the same size, but with a different arrangement and silhouette, so a board full of them does not look repeated.

EACH SHEET: one landscape image, 1536x1024, FOUR sprites in a 2x2 grid (top-left, top-right, bottom-left, bottom-right). Nothing may cross the vertical or the horizontal midline: keep a clear 60 px band of transparency along both midlines. Every sprite about the same size as those in approved-sheet1.png relative to its quadrant.

End of every request: Do not draw grid lines, cell borders, labels, captions, shadows or any background. The background must be alpha 0 everywhere, not white, not a checkerboard. Then apply the true-alpha transparency correction and give me the download link for the corrected PNG. Do not re-render to fix a prop count.

LANDMARK — ancient standing stones with faintly glowing blue runes, a little moss, a few flowers at their feet.
