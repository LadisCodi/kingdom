Managers
---

This feature is an implementation of the managers we use in other Codigames' games. Collectible characters obtained from gacha spins that provide multipliers for your economy and server as gates for certain buildings.

## Progress

Collecting fragments

### List of managers

- A. Improves wood production from trees.
- B. Improves fish production from fish.
- C. Improves wheat production from farmlands.
- D. Improves money production from houses.
- E. Increase power of all military units.
